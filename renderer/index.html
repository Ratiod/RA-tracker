RA TRACKER NOT WATCHING

Setup

Grab a tracker key from the Admin Panel on your tracker site (Tracker Keys tab), paste it below, then hit Save & Connect. Once connected this window can be minimized — RA Tracker keeps watching from the tray and uploads finished scrims on its own.

Watching

When watching, RA Tracker reads Valorant's log file the same way the old .bat script did, but automatically — no need to launch anything after a scrim. It notices a match has ended and uploads it a few seconds later.

Pause stops picking up new matches but lets anything already uploading finish. Stop halts the watcher immediately.
